Sale Product Supplierinfo Search

Search for products by vendor's product code or name

This module enhances the product search capabilities in Odoo, allowing users to find products not only by their internal reference or name but also by the product code and product name defined in the vendor's supplier information. This is particularly useful for distributors and resellers who work with manufacturer part numbers but use their own internal codes on sales documents.

Key Features

  • Seamlessly search on sales order lines by vendor product code.
  • Extends search to include vendor product names.
  • Adds a filter in the main product view for searching in vendor info.
  • Preserves standard search priority, ensuring relevant results.
